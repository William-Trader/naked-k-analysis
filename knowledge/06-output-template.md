# 06 · 输出模板（机器人必须照此输出）

## 格式
```
📊 价格行为简报 | <北京时间>
━━━━━━━━━━━━━━
【市场状态】<趋势/区间/通道/过渡>；高周期：<日线方向>
【BTC】现价 <x>；24h <±x%>；方向：<多/空/中性>（置信度 <0-100>）；周期 4h
结构：<状态判定 + ADX/EMA/RSI/量能/pos20 的具体数字>
主力行为：<吸筹/拉升/派发/观望>；证据：<影线/量能/扫单/背离/资金费率，带价位>
关键位：支撑 <...> / 阻力 <...>
Setup：<H2/L2/DB/DT/楔形/MTR/BLSHS/...>
触发：<具体价位与条件>；失效：<具体价位>；目标：<第一/第二目标>
R:R：<数字>:1（目标距离 ÷ 止损距离；<1.5 不做）
【ETH】同上
【跨品种】<BTC 与 ETH 的相对强弱/同步性>
一句话：<一句话总结，含“等什么确认”>
SIGNAL|BTC|<long|short|neutral>|4h|<confidence>|entry=<...>|stop=<...>|target=<...>
SIGNAL|ETH|<long|short|neutral>|4h|<confidence>|entry=<...>|stop=<...>|target=<...>
非投资建议
```

## 硬性要求
1. 结构判断必须引用 **ADX / EMA20/50 / RSI / ATR% / vol_z / pos20** 的具体数字。
2. 主力行为必须给 **3 条以内证据**，每条带价位或指标。
3. 方向只允许 多/空/中性；周期固定 4h；**禁止 24h 方向预测**。
4. 不给没有数据支撑的百分比概率。
5. 必须给触发/失效/目标；没有就写“等确认”。
6. 纯文本（QQ 不渲染 Markdown 表格），≤700 字。

## 示例（2026-10-20 17:02 实跑）
```
📊 价格行为简报 | 2026-10-20 17:02 北京时间
━━━━━━━━━━━━━━
【市场状态】下跌后的区间整理；高周期：偏空
【BTC】现价 81,567；24h -1.42%；方向：中性（置信度 55）；周期 4h
结构：EMA20 81,901 < EMA50 82,225，价在均线下；ADX 30（趋势）但方向向下；RSI 45.7；ATR 0.90%；vol_z -1.02（缩量）；pos20=0.36（区间下半部）。
主力行为：观望；证据：① 缩量下跌，卖压未加速；② 80,684 下影被买回（下方 limit buy）；③ 无放量派发。
关键位：支撑 80,684 / 80,800；阻力 81,900 / 82,225 / 82,940
Setup：区间下沿的 H2 观察（未触发）
触发：4h 收盘站上 81,900 且 vol_z>+0.5 → 轻仓试多；失效：4h 收盘 < 80,684；目标：82,225 / 82,940
R:R：1.8:1（目标 82,225 ÷ 止损 80,684）
【ETH】现价 2,389；24h -0.43%；方向：中性（置信度 50）；周期 4h
结构：EMA20 2,410 < EMA50 2,443；ADX 30.6；RSI 44.2；ATR 1.46%；vol_z -0.88；pos20=0.51（中轴）。
主力行为：观望；证据：① 缩量；② 2,372 下影被买回；③ 无背离。
关键位：支撑 2,372 / 2,329；阻力 2,410 / 2,446
Setup：区间中轴，无边际优势
触发：4h 收盘站上 2,410 且 vol_z>+0.5 → 偏多；失效：4h 收盘 < 2,372；目标：2,446
【跨品种】ETH 与 BTC 同步偏弱，ETH ATR 更高（1.46% vs 0.90%）
一句话：两者都是空头排列但缩量、价格在区间中部；追空性价比差，等 4h 收盘确认方向。
SIGNAL|BTC|neutral|4h|55|entry=81900|stop=80684|target=82225
SIGNAL|ETH|neutral|4h|50|entry=2410|stop=2372|target=2446
非投资建议
```

## 崔海军《裸K线操盘技法》1 趋势跟踪篇 / 2 投资决策篇

### 1. 异动 = 逆势行为的结果
- 趋势中的“顺势而为”经常买在顶部；真正有价值的是识别**逆势/异动**的脚印。
- 异动包括：放量不涨、缩量不跌、长上影/长下影、假突破、消息刺激后的反向。
- 读法：先问“谁在这个位置逆势接/砸”，再判断主力意图。

### 2. 趋势量化（K线 + 分时）
- 趋势强度 = 连续同向K线数量 + 回调深度 + 量能配合。
- 回调浅（1–3根）、量能缩、收盘靠边 → 强趋势；回调深、量能乱 → 转区间。
- 分时图上的趋势量化用于日内确认，不替代4h结构。

### 3. 相对论（相对强弱）
- 个股/币种相对大盘的强弱，比绝对涨跌更有信息量。
- 大盘跌它不跌/微涨 = 有资金托；大盘涨它不涨 = 有资金压。
- 做多选相对强，做空选相对弱；弱于大盘的反弹不追多。

### 4. 量能逆势
- 量能异变比价格更早暴露主力意图：放量滞涨=派发，缩量下跌=卖压衰竭。
- 量价背离（价新高、量不新高）是动能衰竭的第一信号。

### 5. 主力行为（吸筹/控盘/出货）
- 吸筹：低位温和放量、逆势飘红、通吃套牢密集区、下影线被买回。
- 控盘：高控盘（窄幅、缩量、逆势强）/ 中控盘（区间抬升）/ 低控盘（随波逐流）。
- 出货：高位放量滞涨、长上影、假突破、利好不涨、尾盘砸盘。
- 判断顺序：位置 → 量能 → K线 → 跟随。

## 胡云生《裸K线技术分析与交易》

### 1. 两条横线 + 一条斜线
- 工具极简：**支撑线、阻力线、趋势线**。先画线，再谈方向。
- 支撑/阻力是**交易计划工具**，不是预测工具；目的是确定买/卖/止损位置。

### 2. 支撑/阻力质量
- 高质量支撑：支撑线下方有大阳线 → 随后跳空到线上方 → 第一波回撤不破。
- 就近原则：优先用最近一根K线/最近摆动点画线。
- 只有一条线、没有K线确认 = 低质量，不作为唯一依据。

### 3. 趋势 vs 横盘
- 趋势 = 纵向运动（HH/HL 或 LH/LL）；横盘 = 横向运动（重叠）。
- 先判断运动类型，再谈多空；横盘里不做趋势单。

## 许佳聪《裸K线交易法 · 价格行为全面详解》

- 结构：信号研判 → 盈利空间 → 入场/止损 → 实战 → 金字塔加仓 → 复盘 → 心理。
- 单根K线：大阳/大阴代表一方强势；**不逆势**，等回调顺势入场；底部长期盘整后的大阳线尤其不能空。
- 组合K线：黄昏星/启明星/红三兵/黑三兵；三根以上组合比单根更可靠。
- 入场：等回调到支撑/趋势线/信号K，顺势入场；不追第一根。
- 止损：放在信号K另一端/支撑下方；**止损不能过大**，否则盈亏比失衡。
- 盈利空间：先算目标（前高/测量移动），R:R ≥ 1.5 才做。
- 复盘：4 要素（计划/执行/结果/偏差）；心理：避免“止损过大、止盈敏感”。

## 提纯后新增的硬规则（并入 05 决策树）

1. **先看异动**：放量不涨/缩量不跌/长影线/假突破 → 主力意图线索。
2. **相对强弱**：BTC/ETH/SOL 横向比较；弱于大盘的反弹不做多。
3. **支撑质量评分**：大阳线+缺口+首次回撤 = 高质量；只有一条线 = 低质量。
4. **两条横线一条斜线**：任何分析先画出支撑/阻力/趋势线，再谈 setup。
5. **量能优先于价格**：量价背离时，先信量能。
6. **异动优先于趋势**：趋势末端出现异动，优先按反转/派发处理。

# 01 · 市场结构（先定状态，再谈方向）

> 来源：Al Brooks 市场周期/趋势/区间/通道篇、YTC 趋势方向、许佳聪/胡云生裸K、Adam Grimes。
> 原则：**先看高周期状态，再看当前位置，最后才看单根K线。**

## 1. 四根底层支柱
1. **市场真相 = 净订单流**。K线是结果，不是原因。
2. **供需失衡是唯一引擎**。买压>卖压→涨，反之→跌。
3. **机构 vs 散户博弈**。机构看得见止损堆，会主动扫流动性（stop run）；区间内的“真空”让多数突破失败。
4. **交易者方程**：胜率×回报 > 败率×风险。90% 的时间真实概率只有 40%–60%。

## 2. 市场周期（任何行情都是这条链上的一段）
**突破 BO → 回调（开启通道）→ 通道 → 交易区间 TR → 再突破……**

| 状态 | 识别 | 正确动作 |
|---|---|---|
| 突破 BO | 连续强趋势K、几乎无回调（0–1根） | 只顺势；不逆势 |
| 紧密通道 | 回调1–3根、沿EMA20、少触及通道线 | 顺势，回调买/卖 |
| 宽通道 | 回调3–10根、常触通道线 | 顺势为主，通道边缘可减仓 |
| 交易区间 TR | 20+根重叠、困惑/失望、80%突破失败 | 低买高卖（BLSHS），或等突破确认 |
| 过渡 | 趋势线破 + HL/LH + 二次突破 | 等 MTR 确认，不抢第一根 |

## 3. 趋势判定（多空）
- **多头**：HH+HL，价格在 EMA20 上方，阴线小/阳线大，回调浅。
- **空头**：LH+LL，价格在 EMA20 下方，阳线小/阴线大，反弹浅。
- **Always In**：最近一根强趋势K + 跟随，决定“只做多/只做空”。
- **微通道**：连续 10+ 根几乎不回调 → 强趋势，但**不要追末段**；等第一次像样回调。
- **趋势强度**：ADX≥25 + 连续趋势K + 收盘靠边 = 强；ADX<20 = 无趋势，别给方向。
- **测量移动 MM**：突破段长度从回调点复制，作为第一目标。

## 4. 区间判定（震荡）
- 20+ 根K线重叠、上下影线多、收盘在中部、突破屡屡失败。
- **80% 规则**：区间内 80% 的突破尝试失败；突破需“强收盘 + 跟随”才算数。
- **BLSHS**：Buy Low, Sell High, Scalp——区间下沿买、上沿卖，不追中间。
- 区间持续越久，突破后的行情越大（能量积累）。

## 5. 位置优先级（Location）
1. 高周期（日线/周线）趋势与关键位；
2. 前高/前低、区间边界、测量目标；
3. EMA20/EMA50、VWAP；
4. 当日/本周开盘价、整数关口。
**同一个 setup，在区间上沿做多 vs 下沿做多，胜率完全不同。**

## 6. 状态机（给机器人用）
```
if ADX < 20: state = range_or_transition
elif EMA20 > EMA50 and price > EMA20 and HH/HL: state = trend_up
elif EMA20 < EMA50 and price < EMA20 and LH/LL: state = trend_down
elif 20+ bars overlap and 80% BO fail: state = range
else: state = channel / transition
```
输出必须先写 state，再写方向；state 不清晰时，方向只能是“中性/等确认”。

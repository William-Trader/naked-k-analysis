# 04 · 主力行为分析（订单流 / 筹码 / 流动性）

> 来源：陈浩《筹码分布》、Al Brooks Orders/买压卖压、Wyckoff、YTC 订单流。
> 核心：**主力的痕迹 = 订单流留下的脚印**；不是猜，是从K线/量/位置反推。

## 1. 主力的三种动作
1. **吸筹（Accumulation）**：低位反复震荡、下影线被买回、缩量、逆势飘红。
2. **拉升（Markup）**：突破+连续趋势K+放量；回调浅。
3. **派发/出货（Distribution）**：高位放量滞涨、上影线、假突破、利好不涨。

## 2. 吸筹的四个K线特征（筹码分布）
- 低位**温和吸筹**：小阴小阳、量能温和、价格不再新低。
- **通吃套牢密集区**：放量吃掉上方套牢盘，随后回踩不破。
- **逆势飘红**：大盘跌它不跌/微涨，说明有资金托。
- **低位锁定**：筹码从高位转移到低位并锁定（换手充分）。

## 3. 筹码形态（A股/加密可类比）
- **低位密集**：成本集中，主力控盘度高 → 上涨阻力小。
- **高位密集**：套牢盘重 → 反弹遇阻。
- **双峰**：上下两个密集区，价格在两峰间震荡。
- **低位锁定**：低位筹码不卖，主力锁仓。
- **ASR/CKDP/CKDW/CBW**：活动筹码、相对价位、成本重心、成本带宽——用于判断“谁在拿筹码”。

## 4. 主力控盘/出货
- 控盘模式：**高度控盘**（窄幅、缩量、逆势强）、**中度控盘**（区间抬升）、**低控盘**（随波逐流）。
- 出货形式：高位放量滞涨、长上影、假突破、尾盘砸盘、利好兑现。
- 判断顺序：**位置（高位/低位）→ 量能（放量/缩量）→ K线（上影/下影/实体）→ 跟随**。

## 5. 订单流脚印（Al Brooks）
- **上影线 = 上方有 limit sell**（失败突破/派发）。
- **下影线 = 下方有 limit buy**（吸筹/护盘）。
- **Stop run / 流动性扫单**：快速刺穿前高/前低后立刻收回 = 扫止损，随后反向。
- **Absorption（吸收）**：大成交量但价格不前进 = 一方在吸收另一方的市价单。
- **Failed BO**：突破后无跟随、快速收回区间 = 假突破，反向概率高。
- **90% 规则**：区间内 90% 突破失败；强趋势中才追突破。
- **量价背离**：价格新高但量能/RSI 不新高 = 动能衰竭。

## 6. 加密特有指标（有数据时用）
- **资金费率 Funding**：极高正费率=多头拥挤（易回调）；极负=空头拥挤（易反弹）。
- **持仓量 OI**：价涨+OI涨=新多进场；价涨+OI跌=空头回补（不可持续）。
- **FGI 恐惧贪婪**：极贪/极恐是反向情绪指标，不是方向本身。
- **VWAP**：机构成本线；价格在VWAP上方=多头占优。

## 7. 主力行为 7 问（每次分析必答）
1. 现在在**低位/高位/中位**？（区间位置 pos20/pos40）
2. 最近是**放量还是缩量**？（vol_z）
3. 上影/下影谁更长？谁在被吸收？
4. 有没有**假突破/扫单**（刺穿前高前低后收回）？
5. 价格与量能/RSI 有没有**背离**？
6. 资金费率/OI 是否拥挤？
7. 主力的**成本区**在哪（筹码密集/EMA/VWAP）？

> 结论必须落到：**吸筹 / 拉升 / 派发 / 观望** 四选一，并给出证据价位。

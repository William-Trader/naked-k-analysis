# 03 · Setup 清单（在什么状态、什么位置、怎么触发）

> 每个 setup 都写清：**前提状态 → 位置 → 触发 → 失效 → 目标**。没有触发就不算 setup。

## A. 趋势跟随类
### A1. H1 / H2（牛趋势回调买入）
- 前提：多头结构（HH/HL，价在EMA20上）。
- 位置：回调到EMA20/前突破点/区间上沿回踩。
- 触发：H1=第一次回落后的信号K；H2=第二次回落不破前低，买stop挂在信号K高点上1 tick。
- 失效：跌破H2低点/前一个HL。
- 目标：前高→测量移动（突破段长度复制）。
- 备注：H3/H4在强趋势中更可靠；H2失败常变TR。

### A2. L1 / L2（熊趋势反弹做空）
- 镜像：LH/LL，价在EMA20下；L2不破前高；卖stop挂信号K低点下1 tick。
- 失效：突破L2高点/前一个LH。

### A3. 突破回踩（BO PB）
- 前提：强突破（大实体+跟随+收盘靠边）。
- 位置：回踩突破点/EMA20，不跌回区间。
- 触发：回踩后出现同向信号K。
- 失效：跌回突破前区间。
- 目标：测量移动。

### A4. 微通道第一次回调
- 前提：10+根几乎不回调的微通道。
- 动作：**不追末段**；等第一次像样回调（H1/H2）再做。
- 失效：回调超过通道起点/20根。

## B. 反转类
### B1. 双底/双顶（DB/DT）
- 前提：两次探低/冲高失败；第二腿常是楔形/高潮。
- 触发：颈线突破 + 跟随；或 DB PB（双底回调买入）。
- 失效：跌破双底低点/突破双顶高点。
- 目标：颈线到顶/底的距离（MM）。

### B2. 楔形反转（三推）
- 前提：三次推进，第三次动能衰竭（实体变小/影线变长/量能背离）。
- 触发：楔形趋势线破 + 反向信号K。
- 失效：再创新高/新低。
- 目标：楔形起点/测量移动。

### B3. 最终旗形（Final Flag）
- 前提：趋势末段，紧凑旗形/三角形/TR。
- 触发：旗形突破失败（假突破）→ 反向。
- 失效：真突破并跟随。
- 目标：回到旗形起点/前一段的MM。

### B4. MTR（主要趋势反转）
- 三步：①趋势线破；②HL/LH 形成；③二次突破（强信号K）。
- 触发：第二步确认后的反转信号K。
- 失效：重新站上趋势线/前高。
- 目标：前一段的起点/MM。

### B5. 头肩 / 圆弧顶底
- 前提：左肩-头-右肩（或圆弧），右肩动能弱。
- 触发：颈线破 + 跟随。
- 失效：回到颈线上方。
- 目标：头到颈线的距离。

## C. 区间类
### C1. BLSHS（区间低买高卖）
- 前提：TR 成立（20+根重叠，80%突破失败）。
- 位置：区间下沿买、上沿卖；**不在中间追**。
- 触发：边缘出现反向信号K（pinbar/吞没）。
- 失效：区间边界被强收盘突破。
- 目标：区间另一侧。

### C2. 区间突破（只做确认突破）
- 前提：区间够久、能量积累。
- 触发：强收盘突破 + 跟随 + 回踩不破。
- 失效：跌回区间（假突破）。
- 目标：区间高度复制（MM）。

## D. 缺口 / EMA
- **缺口**：突破缺口=趋势延续；衰竭缺口=回补。
- **EMA20 回调**：强趋势中第一次触EMA20 + 信号K，是低风险入场。

## E. 概率提示（来自 Brooks）
- 区间内突破：80% 失败。
- 强趋势中回调：H2/L2 成功率高于 H1/L1。
- 高潮后：常有 2 条腿回调；不要在第一根反转K全仓。
- 任何 setup：**先看位置，再看形态**；位置错，形态对也会亏。

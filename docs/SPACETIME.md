# 时空分析体系（2.3.0，`nakedk/spacetime.py`）

> 设计目标：把「固定 15m 执行 + 4h 偏向」升级为**自适应尺度轴 + 价格结构空间状态**，并让每个判断都能用中文一句话解释。
> 定位：**描述性分析层**。默认关闭、不参与交易门禁。本文所有数字可用冻结快照复现。

## 1. 为什么改

旧体系把两个观察窗口写死：`DEFAULTS["intervals"] = ["15m","4h"]`。这混淆了三个不同问题：

| 问题 | 旧体系 | 时空体系 |
|---|---|---|
| 当前趋势由哪个时间尺度承载 | 固定 4h | 从 1h 基础序列重聚合 1h/2h/4h/8h/1d，用「净位移/总路程」选 `dominant_scale` |
| 价格在结构中的什么位置 | `pos20`（20 根分位） | 40 根摆动高低构成结构区间 + 分位 + 关键位触碰的**时间衰减权重** |
| 结构如何随时间演化 | 无 | 速度 / 加速度（ATR 归一化）、level age、session 时段、状态 ID |

因此 15m 不再是先验执行框架；尺度由数据决定。

## 2. 状态字段（全部只使用 bar i 及之前的数据）

`build_state(ks4, ks1, index)` 把 1h 序列在 4h bar 收盘时刻截断，**无未来函数**。

| 字段 | 含义 | 计算 |
|---|---|---|
| `dominant_scale_h`、`scale_scores` | 各尺度路径效率最高者 | `|net| / Σ|Δclose|` on 1h/2h/4h/8h/1d 聚合 |
| `path_efficiency`、`regime` | 趋势/区间 | 最近 24 根 1h 的净位移/总路程，阈值 0.30 |
| `position`、`position_bucket` | 结构分位 | 40 根 4h 摆动区间内的归一位置 |
| `velocity`、`acceleration` | 位移一阶/二阶 | 6 根 1h 净位移 / ATR14，及其变化 |
| `level_touches`、`level_touch_weight` | 关键位被验证的强度 | 触碰次数按半衰期 24 根指数衰减 |
| `session`、`state_id` | 时段与离散状态 | UTC 分桶；`尺度|趋势态|位置桶|时段` |

`describe(state)` 输出一行中文解释，面板「时空状态」卡片逐项展示，`state_id` 可用于后续分桶复盘。

## 3. 决策规则（v2）

`admit()` 是**纯规则、只做减法**，不做收益拟合：

- 趋势态：要求速度同向、加速度不出现强反转；短主导尺度还要求结构边缘。
- 区间态：边缘逆势（做多在低位 / 做空在高位）；中部交易需速度与加速度同时配合；关键位须有时间加权验证。
- 一律拒绝：`|velocity| > 3 ATR` 的追高杀跌、历史不足、无明确方向。

v1 曾把「主导尺度长于持仓周期」判为拒绝 —— 这是逻辑反了（长尺度主导恰是趋势更持久的证据），且规则过严只产生 4 笔训练交易。v2 修正后样本量恢复。

## 5. 诚实的结论与纪律

- **validation 上时空体系表现好，test 上明显转负** → 典型的 regime 变化 / 规则过拟合迹象。
- 更关键：**v2 规则是在看过 v1 的 test 结果之后修改的**，因此 test 段已被使用两次，不再构成干净的样本外验证。继续按这个 test 调规则就是数据窥探。
- 唯一 test 只评估过一次的配置是 **2.2.0 的 v22 champion**。因此：
  - 保留 v22 作为唯一被采纳的可选门禁（`NK_RESEARCH_GATE=1`）；
  - 时空体系**不提升为交易门禁**，定位为描述性分析层（`NK_SPACETIME=1`），用于解释「当前哪个尺度在主导、价格在结构哪里、动能如何演化」；
  - 要晋升为门禁，需要**新的、从未参与过任何调参的数据段**（例如下一季度的实盘/新快照）做一次性验证。

**行业最优不是一个可验证的验收口径**；本文提供的是可复现、可解释、可证伪的口径。任何"最优"主张都必须附带新的独立样本外结果。

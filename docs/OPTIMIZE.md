方法：特征缓存后跑完整网格，240 天、2 标的（BTC/ETH）、8 折、12bp 成本、1h 盘中路径。
每组参数逐行落盘，避免会话中断丢结果。

## 结论

- **18 组参数里，0 组平均收益为正。**
- 最好的一组（stop 1.5 / target 2.0 / ADX 22）平均 −0.034%，t = −0.66，连“显著为负”都算不上，只是接近零的负漂移。
- ADX 18 与 20 结果完全相同，说明在该样本里 ADX 18–20 之间没有额外信号被过滤，参数不敏感。
- 因此：**该规则集在方向预测上没有可调出的正期望**。继续调参只会得到更小的负值或过拟合。

## 决策

1. 不部署任何“优化后参数”作为交易建议。
2. 方向判断保留为**描述性输出**，不作为入场依据。
3. 后续研究转向：区间回归、失败突破、吸收/扫单等不依赖方向预测的结构性机会。
4. 若仍要做方向，必须先改变特征或市场（例如加入订单流/期权/跨市场），而不是继续调阈值。

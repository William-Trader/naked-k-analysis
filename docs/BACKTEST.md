# 回测记录（含 1h 盘中路径与成本）

方法：4h 信号、4h 持有、1h 路径判断先触止损还是目标、双边成本 12bp、4 折顺时序。
命令：`python -m nakedk backtest BTCUSDT ETHUSDT --days 120 --folds 4 --cost-bps 12 [--gate ...]`

## 第 1 轮：无门禁（baseline）

| 标的 | 平均命中 | 折间稳定 | 四折 n | 四折 avg% |
|---|---|---|---|---|
| BTC | 35.0% | 0% | 21/27/28/62 | -0.173 / -0.073 / -0.032 / -0.264 |
| ETH | 41.0% | 0% | 20/28/32/52 | -0.283 / -0.065 / -0.195 / -0.126 |

结论：四折全负，无 edge。

## 第 2 轮：严格质量门禁（ADX≥25、ADX 斜率≥0、重叠<0.5）

| 标的 | 交易数 |
|---|---|
| BTC | 0 |
| ETH | 0 |

结论：门禁过严，等于“不出手”。这不是优化，是没有样本。

## 第 3 轮：宽松门禁（ADX≥20、斜率≥-1、重叠<0.65）

| 标的 | 平均命中 | 折间稳定 | 四折 n | 四折 avg% |
|---|---|---|---|---|
| BTC | 29.7% | 25% | 10/8/4/13 | +0.105 / -0.081 / -0.578 / -0.197 |
| ETH | 46.5% | 25% | 2/2/10/24 | +0.748 / -0.702 / -0.09 / -0.105 |

结论：样本被压到 2–24 笔，Wilson 区间极宽，不能据此宣称有效；跨折稳定仅 25%。

## 解释

- 三版没有任何配置在四折上同时为正，不能挑单折“最好看”的数字当结论。
- 12bp 成本 + 1h 盘中路径后，原本边际的信号转负，这是真实约束。
- 早前 365 天、仅按 4h 收盘的 49% 数字与本次不可比（窗口、成本、路径都不同）。
- 门禁把交易数打到 0 或个位数，说明“过滤器”比“信号”更强势，方向应改为条件概率而非硬过滤。

# 价格行为（裸K）分析框架

> 本框架由 pa_fetch.py 提供数据、由 LLM（DeepSeek）执行分析，是机器人推送简报的判读标准。

## 一、数据输入
- 脚本：python3 pa_fetch.py BTCUSDT ETHUSDT（可传任意币种符号）
- 数据源：Binance 公共端点 data-api.binance.vision（无需 API Key）
- 内容：现价与 24h 变化 / 4h K线（最近 42 根）/ 1h K线（最近 24 根）/ ATR(14) / 最近 20 根区间 / 量能相对均值

## 二、分析结构（输出模板）
1. 标题行：📊 价格行为简报 | <北京时间>
2. 现价与 24h 变化
3. 市场结构判断：趋势 / 区间（依据：摆动高低点、K线重叠度、ATR 方向）
4. 关键价位：支撑 / 阻力，给具体数字（依据：最近摆动点、区间边界）
5. 情景推演：2-3 个，每个带触发价位与目标
6. 一句话总结
7. 结尾：非投资建议

## 三、输出约束
- 纯文本（无 Markdown 表格/标题符号），可用 emoji 与分隔线
- 总长 ≤ 600 字
- 面向加密资产投资者，中文

## 四、范围与免责
- 仅覆盖技术面（价格行为），不含基本面 / 链上 / 情绪
- 不构成投资建议

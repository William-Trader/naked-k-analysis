# 趋势能力检验（2026-10-20）

## 方法

- 样本：BTCUSDT / ETHUSDT 4h，730 天，各 4300 根
- 状态机：
  - ADX < 20 → range
  - EMA20 > EMA50 且 price > EMA20 → up
  - EMA20 < EMA50 且 price < EMA20 → down
  - 其余 → transition
- 标签 A（严格趋势）：未来 20 根收益 > +2% 且期间最大回撤 > -2% → up；镜像 down；否则 range
- 标签 B（方向）：未来 20 根收益符号，剔除 abs(ret) < 0.5%
- 标签 C（趋势/区间）：abs(ret) > 1.5% → trend，否则 range

## 结果

| 指标 | BTC | ETH |
|---|---|---|
| 严格标签准确率 | 26.7% | 29.6% |
| 严格方向命中 | 22.8% | 27.0% |
| 方向命中（0.5% 阈值） | 45.4% | 48.4% |
| 反向命中 | **54.6%** | 51.6% |
| 趋势/区间准确率 | 52.8% | 56.9% |

## 结论

1. **当前状态机是“描述当前结构”，不是“预测未来方向”。** 20 根方向命中低于随机。
2. BTC 略反向（inverse 54.6%）：它在趋势末端仍标 up/down，容易在拐点站错边。
3. trend/range 准确率 52.8%/56.9%，只比基线略好——不能单独作为方向依据。
4. 这不否定知识库的价值：结构/位置/setup 用于**条件化分析**是有效的；无效的是“用状态直接推方向”。

## 改进方向（已写入 playbook 的约束）

1. **多周期共振**：日线趋势 + 4h 状态同向才给方向。
2. **趋势强度分级**：ADX、EMA 斜率、HH/HL 计数，而不是三态硬切。
3. **位置优先**：区间边缘不追单（pos20 硬规则）。
4. **状态与预测分离**：状态=描述；预测=条件概率（必须给触发/失效）。
5. LLM 只做叙述与综合，不负责预测；所有数字来自 SIG 行。
